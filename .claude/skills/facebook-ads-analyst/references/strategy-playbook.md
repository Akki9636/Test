# Strategy playbook

Build the plan from the diagnosis — never generic advice. Every plan item must
name the entity it applies to and the gap (from diagnostics.md) it addresses.

## Budget reallocation rules

- Scale winners ≤ 20% per day (or duplicate at higher budget into a new ad set)
  to avoid resetting learning.
- Kill rule: spend ≥ 3× target CPA with 0 results, OR ≥ 2× target CPA sustained
  over 2+ weeks after a fix attempt → pause.
- Fund scaling from kills first; only then propose net-new budget.
- Keep 10–20% of budget as a permanent testing allocation.

## Account structure recommendations

- Consolidation: prefer fewer ad sets with ≥ 50 conversions/week each over many
  fragmented ones. If most ad sets are stuck in learning, recommend merging.
- Separate prospecting and retargeting campaigns; cap retargeting at ~10–20% of
  spend unless data justifies otherwise.
- For ecommerce at meaningful spend, evaluate Advantage+ Shopping as a structural
  test against manual campaigns.

## Creative testing cadence (anti-fatigue pipeline)

- 2–4 new creatives per week into the testing budget, testing **angles**
  (pain point, social proof, offer, demo, UGC) before variations.
- Promote a test winner to the main campaign only after ~statistically meaningful
  results (≥ 20–50 conversions or clearly dominant CTR+CVR on real spend).
- Retire creatives when frequency-adjusted CTR drops > 30% from its peak.

## 30-day plan template

- **Week 1 — Stop the bleeding**: tracking fixes, kill list, budget reallocation,
  launch first creative test batch.
- **Week 2 — Fix the biggest gap**: the #1 ranked gap from analysis (creative,
  landing page, structure). Second test batch.
- **Week 3 — Validate & iterate**: read week-1/2 results (respecting attribution
  lag), promote winners, kill losers, structural test if planned.
- **Week 4 — Scale & systematize**: scale validated winners 20%/day, document the
  ongoing testing cadence, set re-analysis date.

## Measurement plan rules

- Pick 3–5 KPIs tied to the gaps found (e.g. if Stage-2 gap: link CTR weekly; if
  Stage-4: CVR weekly), each with current value → target value → review date.
- Always include the money metric (CPA or ROAS) plus its leading indicator.
- Recommend a fixed weekly review using the same export settings so reports stay
  comparable (same attribution window, same columns, same level).
